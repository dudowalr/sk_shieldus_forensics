# SK Shieldus Forensics Project

SK쉴더스 루키즈 프로젝트에서 제작하거나 활용한 데이터 수집 도구,
취약점 재현 환경 및 보안 실습 자료를 관리하는 저장소입니다.

> [!WARNING]
> 일부 파일에는 의도적으로 취약한 소프트웨어와 자동 실행형 공격
> 시뮬레이션 코드가 포함되어 있습니다. 반드시 허가된 폐쇄형 실습망과
> 격리된 분석 환경에서만 사용하십시오.

## 주요 구성

### SQL Server DBMS 접근 및 데이터 추출 도구

`c_sqlserver_collect.bat`은 Microsoft SQL Server의 `sqlcmd`, `bcp`
및 DBMS 자체 기능을 활용해 원격 또는 로컬 SQL Server에 접속하고,
데이터를 원하는 출력 경로로 추출할 수 있도록 구성한 Windows용
자동화 도구입니다.

SQL Server에 접근하는 데 필요한 서버 주소와 포트 지정, Windows
통합 인증, SQL Server 계정 인증, 서버 인증서 신뢰 옵션 등을 하나의
실행 구문으로 사용할 수 있도록 정리했습니다.

접속 후에는 접근 가능한 사용자 데이터베이스와 테이블을 자동으로
확인하고 다음 정보를 추출합니다.

- 사용자 데이터베이스 및 테이블 데이터
- 각 테이블의 BCP 원본 데이터
- 분석과 확인에 사용할 수 있는 CSV 데이터
- 데이터베이스, 테이블, 컬럼 및 인덱스 메타데이터
- 실행 과정과 오류가 기록된 로그
- 생성된 파일의 SHA-256 해시 목록

SQL Server가 제공하는 표준 접근 및 데이터 처리 기능을 이용하므로,
별도의 에이전트를 DBMS 서버에 설치하지 않고도 권한이 허용된 범위
안에서 데이터 확인과 추출 작업을 수행할 수 있습니다.

### React2Shell 격리 실습 서버

`react_server_was/`는 React Server Components 취약점인
React2Shell(CVE-2025-55182)의 동작을 확인하기 위한 Next.js 기반
격리 실습 환경입니다.

Next.js `15.0.4`, React `19.0.0`, React DOM `19.0.0`을 고정해
사용하며 다음 기능을 포함합니다.

- React Server Action 테스트 페이지
- 외부 요청을 내부 Next.js 서버로 전달하는 HTTP 로깅 프록시
- 요청 헤더, 본문, 응답 상태 및 처리 결과를 기록하는 JSONL 로그
- HTTP 응답을 통한 Next.js 및 React 버전 확인
- IP 주소와 포트 변경을 위한 환경변수
- Windows 서버 배포용 ZIP 파일

구축 방법, 환경변수, 빌드·실행 명령, Windows 방화벽 설정 및 문제
해결 방법은 [`react_server_was/README.md`](./react_server_was/README.md)에서
확인할 수 있습니다.

### React2Shell Windows 배포본

`react_server_was/react_server_was.zip`은 React2Shell 실습 서버를
다른 Windows 서버에 배포하기 위한 압축 파일입니다.

압축을 해제한 서버에서 다음 순서로 설치하고 실행할 수 있습니다.

```bat
npm ci
npm run build
npm run start
```

`node_modules/`, `.next/` 및 실행 중 생성되는 로그는 배포본과
저장소에 포함하지 않습니다.

### 채용 사이트 프런트엔드 예제

`frontend.zip`은 가상의 무인기 회사 채용 사이트를 구현한
프런트엔드 예제입니다.

HTML, CSS, JavaScript로 구성된 정적 웹사이트와 Python 표준
라이브러리를 사용하는 로컬 웹서버를 포함하며 다음 기능을 제공합니다.

- 채용공고 검색 및 직무 분류 필터
- 지원 안내 팝업
- 채용 이메일 주소 복사
- 반응형 화면 구성
- Windows용 실행 스크립트

### 공격 시뮬레이션 샘플

`resume_2.zip`과 `200.doc`은 사회공학 및 문서 기반 공격 흐름을
확인하고 분석하기 위한 보안 실습 자료입니다.

`resume_2.zip`에는 이력서로 위장한 문서와 LNK, HTA 파일이 포함되어
있으며, 숨겨진 PowerShell 명령 실행과 외부 연결 동작을 재현합니다.

`200.doc`은 VBA 매크로와 자동 실행 진입점이 포함된 구형 Word 문서
형식의 실습 샘플입니다.

> [!CAUTION]
> 해당 파일은 일반 업무용 PC에서 열거나 실행하지 마십시오.
> 네트워크와 시스템이 격리된 분석 환경에서만 취급해야 합니다.

## 사용 시 주의사항

- 모든 실습은 사전 승인을 받은 시스템과 네트워크에서만 수행합니다.
- 취약점 재현 서버를 인터넷이나 실제 업무망에 공개하지 않습니다.
- 실제 계정, 쿠키, 인증 토큰 및 운영 데이터를 실습에 사용하지 않습니다.
- 공격 시뮬레이션 파일은 일반 사용자 PC에서 실행하지 않습니다.
- 수집한 데이터와 로그는 접근 권한 및 보존 기간을 별도로 관리합니다.
